# 에뮬레이터 시연 절차 (화면 녹화용)

가상화(KVM)가 되는 PC나 Mac에서 진행합니다. 영상의 숫자는 `SampleScenarioTest`의 가상 예시와 같게 맞춥니다.

## 준비 (약 20분)

1. Android Studio SDK Manager > SDK Update Sites에 Pleos 에뮬레이터 주소를 추가합니다.
   - Linux/Windows: `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
   - Mac(Apple 칩): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
2. API 34 "Pleos Connect v2.1.0" 이미지로 AVD를 만들고(RAM 4GB) 콜드 부팅합니다.
3. `adb install -r apk/<배포 APK>` 후 앱을 열고 차량 속도 권한을 허용합니다.
4. 설정 탭: 법인명 `가상예시 주식회사`, 차종 `그랜저 하이브리드 (가상 예시 차량)`, 등록번호 `00가 0000`,
   사용자 `김예시 / 영업팀`, 차주 PIN 4자리. 저장한 뒤 현재 PIN을 넣고 '시연 모드'를 켭니다
   (가상 신호 버튼이 나오고, 시연 중에는 가족 알림이 나가지 않습니다).
5. `adb forward tcp:8088 tcp:8088`, 브라우저에서 `http://127.0.0.1:8088/` (가상 콘솔)
6. 녹화: 앱 화면은 `adb shell screenrecord --bit-rate 8000000 /sdcard/autobrief.mp4`(최대 3분),
   가상 콘솔은 PC 화면 녹화로 함께 찍어 좌우로 붙입니다.

## 장면 1. 운행기록부 (40초)

1. 가상 콘솔에서 계기판(Odometer)을 45,200 km로 맞추고 기어 P.
2. 기어를 D로 바꿉니다. 앱 상단에 기어 D가 보입니다.
3. 계기판을 45,218 km까지 올립니다(가상 콘솔은 1km 단위).
4. 기어를 P로 바꾸면 운행기록 탭에 `45,200.0 → 45,218.0 km (18.0 km)` 미분류 주행이 생깁니다.
5. 음성 또는 화면에서 '일반 업무'를 고르고 비고에 `가상고객사 미팅`을 넣습니다.
6. '사업연도'를 눌러 ⑪ 총주행 거리, ⑫ 업무용 사용거리, ⑬ 업무사용비율을 보여 주고, '운행기록부 만들기'를 누릅니다.

## 장면 2. 수면 케어 (30초)

1. 가상 콘솔의 좌석 착석(Seat Occupancy)에서 2열 오른쪽을 켜고 독서등(Reading Lights)을 끕니다.
2. 가상 콘솔에 등받이 항목이 없으므로, 앱의 '시연용 가상 좌석 신호'에서 '2열 오른쪽 등받이 젖힘(가상)'을 누릅니다.
   화면에 가상 신호라고 표시된 채로 찍습니다.
3. 60초 뒤 '잠든 것 같음'과 순정 '후석 취침 모드' 안내가 뜹니다(영상에서는 대기 구간을 잘라 냅니다).
4. 가상 콘솔의 실내 조명 밝기(Ambient Brightness)가 바뀌는지 확인합니다. 바뀌지 않으면 앱이 '이 차량은 조명 조절을
   앱에 열어 두지 않았습니다'를 보여 주며, 그 화면 그대로 찍습니다.

## 장면 3. 대리운전 (40초)

1. 순정 내비에서 목적지를 하나 정합니다(가상 주소).
2. 대리운전 탭에서 '대리운전 모드 시작'을 누르고, 동의 창에서 '동의하고 시작'.
3. 기어 D, 계기판을 45,218에서 45,229 km로 올립니다.
4. 가상 콘솔에 차량 속도 항목이 없으므로 '시연용 가상 급감속 1회'를 눌러 급감속 1회를 보여 줍니다.
5. 에뮬레이터 내비가 도착을 알리지 않으면 '시연용 가상 도착 신호'를 누른 뒤 기어 P, 이어서 문 잠금(Door Lock)을 켭니다.
   최근 기록에 '도착 후 주차, 주행 11 km, 급감속 1회'가 뜨고, 문을 잠그면 '문 잠김 예'로 바뀝니다.
6. 시연 모드이거나 보내기 주소가 없으면 알림은 나가지 않습니다. 그 화면 그대로 찍습니다.
